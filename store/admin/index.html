Objetivos

Segunda forma de navegar no menu da loja, ao lado das categorias. Marque os objetivos de cada produto no editor do produto. Só aparecem na loja os objetivos com produtos.

    Como funciona

    A ordem aqui é a ordem dos filtros na loja. As duas primeiras categorias com produtos aparecem em destaque na página inicial.

    Ocultar uma categoria esconde-a da loja, e todos os seus produtos deixam de poder ser encomendados. Nada é apagado.

    Para eliminar uma categoria com produtos, escolha para onde movê-los.
